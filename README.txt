تحديث واجهة MFFT

استبدل الملف الحالي src/App.jsx بهذا الملف فقط، مع إبقاء src/supabase.js وبقية المشروع كما هي.

يتضمن الملف:
- دخول المدير والتحقق من جدول admins.
- إضافة الطلاب عبر Edge Function admin-create-student.
- قراءة قائمة الطلاب من mfft_students.
- إنشاء الاختبارات وإدارتها عبر mfft_tests.
- بنك أسئلة لإضافة السؤال وصورته الأصلية وثمانية بدائل، وحفظ موضع الإجابة الصحيحة في mfft_options.
- دخول الطالب عبر Edge Function student-login.

تنبيه: فحص TypeScript أكد سلامة صياغة JSX، لكن لم يتم تشغيل npm build أو تجربة الاتصال بقاعدة Supabase الفعلية. يستخدم بنك الأسئلة أسماء الجداول mfft_questions وmfft_options ويحاول التوافق مع عدة أسماء شائعة لأعمدة الصور والترتيب؛ يجب اختبار حفظ سؤال تجريبي قبل نشره للطلاب.
